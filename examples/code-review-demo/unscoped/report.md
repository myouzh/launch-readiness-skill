## 项目关注点

### F-001 · P1 · 登录保护后仍仅按文档 ID 读取，未绑定租户
证据类型: 静态事实（不等于漏洞复现）
E-002, E-003, E-004, E-005, C-001

**优先级理由**: 此唯一读取入口返回文档正文；合法登录不等于文档授权，需先处理查询边界。优先级不是已复现漏洞严重度。

**业务影响**: 若有效登录用户获知其他租户文档 ID，且运行环境无额外隔离，可能读取异租户文档正文及租户字段；未观测实际泄露。

**观察**: 预期读取同时受验证身份租户约束；实际 server.js:5-6 挂载身份验证后进入 documents.js:3-6，查询只使用请求 ID，命中直接返回整行；schema.prisma:1-5 虽有 tenantId，却未进入授权判断。

**已检查的反证**: auth.js:2-7 会验证 JWT 并在失败时返回 401，排除未登录任意读取说法。检查全部五个文件后未发现可达 helper、调用方租户校验或模型中的额外防护；数据库外部策略仍未知。

**尚不确定**: 依赖有效 JWT、已知异租户 ID、存在目标记录、可运行路由与无独立数据库隔离；简化快照并非部署系统，无 TEST 授权或复现，不能定性为已确认利用。
